# Customer Purchase Prediction

## Project Overview

This project uses machine learning to predict whether a customer is likely to make a purchase. The Streamlit application uses the final model selected by the training script and displays the predicted result and estimated purchase probability.

## Machine Learning Models

The project compares two machine learning models:

- Decision Tree
- Naive Bayes

The final model is selected by comparing the models' F1 scores during cross-validation. The selected model is saved as `customer_purchase_model.pkl` and is used by the Streamlit application.

## Dataset

The project uses two Excel files during model development:

- `Training Dataset.xlsx`
- `Testing Dateset.xlsx`

The training dataset contains 177,086 records and the testing dataset contains 44,272 records. The testing dataset does not contain actual target labels, so its predictions cannot be used to calculate accuracy or other labelled evaluation metrics.

The target column is `Result`:

- `0` = No Purchase
- `1` = Purchase

Dataset source: Susu Hao (Suki), *Buy or Not: Purchase Intent Prediction Challenge* (2025), Kaggle:
https://www.kaggle.com/competitions/buy-or-not-purchase-intent-prediction-challenge

Dataset use must follow the Kaggle competition rules:
https://www.kaggle.com/competitions/buy-or-not-purchase-intent-prediction-challenge/rules#7-competition-data

## Project Files

Keep these files in the same project folder:

- `app.py` — Streamlit application.
- `customer_purchase_model.pkl` — saved final model pipeline generated by the training script.
- `model_columns.pkl` — feature columns used by the model.
- `requirements.txt` — Python libraries required by the application.
- `Customer_Purchase_Prediction_Two_Models_Path_Fixed.py` — training and evaluation script.

The Excel datasets are used for model development. They are not needed to run the deployed application because the trained model is saved in the model file.

## Run the Application Locally

Install the required libraries:

```bash
pip install -r requirements.txt
```

Start the Streamlit application:

```bash
streamlit run app.py
```

The application will open in your web browser. If it does not open automatically, visit:

`http://localhost:8501`

## How to Use the Application

1. Enter the customer and sales details in the form.
2. Click **Predict Purchase**.
3. The application displays either Purchase or No Purchase.
4. The purchase probability shows the model's estimated likelihood of a purchase.

## Deployment

The application can be deployed through Streamlit Community Cloud by connecting the GitHub repository and selecting `app.py` as the main file.

## Note

The prediction is an estimate produced by the trained model. It should be used as supporting information and not as the only basis for business decisions.
